# Rock-Paper-Scissors CLI

A command-line based Rock-Paper-Scissors game written in Python. 

### Learning Objectives
This script was created to practice:
- `while` loops and user input validation.
- Control flow (`if/elif/else`) and boolean logic.
- Modular programming by separating the core logic into specific functions.

### AI Assistance Workflow
*I used an AI code assistant to review my `determine_winner` function. It suggested combining the winning conditions into a single `elif` statement using the `or` operator, which made the code much cleaner and easier to read.*

### How to run
```bash
python game.py
